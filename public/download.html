    v1.59.60 2026-11-08 最新
    查看全部版本
    • 新增画线快捷键按 TradingView 的方式工作：鼠标在 K 线区时，Alt+H / Alt+J / Alt+V / Alt+C 直接在鼠标处画出水平线、水平射线、垂直线、十字线（带磁吸），鼠标在别处时仍只是选中工具；Ctrl+X 剪切画线，Esc 取消选中，画矩形时按住 Shift 画正方形。画线工具的提示和下拉菜单每行右侧标出对应按键。
    • 新增X 键显示或隐藏历史交易连线，和显示菜单、设置里的「历史交易连线」是同一个开关，重启后保留。
    • 新增画线模板菜单里可以删除已保存的模板：鼠标移到模板上会出现删除按钮。
    • 优化快捷键在 Windows 上写成 Ctrl / Alt / Shift，以前设置里的快捷键列表在 Windows 上也显示 Mac 符号；图表右键「粘贴绘图」标出按键，策略条件编辑器在 Windows 上提示按 Ctrl+Enter 保存。
    • 修复编辑一条画线时，其他画线也会被改动，锁定的也不例外：落在周末、缺数据的日子或窗口外的端点，会被挪到前一根 K 线上。
    • 修复只在当前周期显示的画线，切换周期后有时还留在图上，位置也不对；开着画线同步拖动画线时，不该显示它的窗格里也会出现预览；Tick 图表不理会画线的显示周期设置。
    • 修复系统切换浅色或深色后，自己改过的图表颜色（比如止损线的颜色）每次启动都会被重置；有几档回放速度（比如 M1 上的 ×10、×50）重启后会变回 ×60。
    • 修复登录：杀毒或备份软件占着登录文件时，刷新后的登录状态会丢；登录文件一时读不出来时，软件会退出账号、换一个新设备号，多占一个设备名额。现在会等文件释放，读不出来时保持原样。
    • 修复MT5 的允许地址：设置、实盘检查清单和 EA 提示统一写 127.0.0.1。以前设置里写的 http://127.0.0.1:7311 只能让同步连上，实盘连接会失败。
